FormuDoku

정답 숫자를 수식으로 만드는 스도쿠

빈칸을 고르면 서버가 숫자와 연산 기호를 제공합니다. 주어진 재료로 스도쿠 정답을 만들고, 같은 칸의 수식을 더 높은 점수로 개선할 수 있습니다.

ROLE CONTRIBUTION

내 역할과 AI의 역할

내 역할

풀이가 가능한 재료, 수식 수정 시 점수 차액, 한 칸에 여러 후보 숫자를 적는 메모 규칙을 정했습니다.

ChatGPT의 역할

수식 파서와 서버 판정, 점수와 랭킹 저장, 후보 메모 UI를 구현하고 자동 테스트를 작성했습니다.

CASES IMPLEMENTATION

구현 사례

CASE 01 퍼즐 생성

무작위 재료로도 풀 수 있는 빈칸 만들기

목표
재료를 무작위로만 뽑으면 주어진 숫자와 기호로 정답을 만들 수 없는 칸이 생깁니다.
바꾼 점
서버가 정답 수식에 필요한 재료를 먼저 넣고 나머지를 섞습니다. 재료 하나는 한 번씩 쓰고, 일부만 사용해도 제출할 수 있습니다.
결과
기본 12개와 전문가 15개 재료에서 정답 수식이 가능한지 검사했습니다.
실제 요청 발췌 / 풀이 가능한 재료 보장 
서버에서는 최소한 1가지 이상의 정답 루트를 만들어줘야해

CASE 02 점수 규칙

같은 칸은 기존 최고 점수보다 오른 만큼만 지급

목표
정답을 맞힌 칸에서도 더 긴 수식을 시도할 수 있게 하고, 이미 받은 점수의 중복 지급을 막았습니다.
바꾼 점
숫자와 연산 기호 수로 점수를 계산합니다. 기존 최고점을 넘을 때만 점수 차이를 추가하고, 낮은 점수의 재제출은 기존 최고 수식을 유지합니다.
결과
Worker와 SQLite 기반 D1 테스트에서 최고 수식 유지와 완료 게임의 랭킹 기록을 확인했습니다.
  1. 2 + 5로 300점
  2. 3 x 4 - 5로 500점
  3. 차이인 200점 추가

CASE 03 플레이 편의

한 칸에 여러 후보 숫자를 메모

목표
한 칸에 숫자 하나만 적을 수 있어 후보가 여러 개면 비교하기 어려웠습니다.
바꾼 점
후보를 칸 안에 작게 표시하고, 같은 숫자를 다시 누르면 그 후보만 지웁니다. 정답을 제출한 칸의 메모는 자동으로 지웁니다.
결과
새로고침 후 복원, 이전 단일 메모 호환, 오답 시 메모 유지 동작을 검사했습니다.
  1. 후보 숫자 여러 개 기록
  2. 같은 숫자를 눌러 개별 삭제
  3. 정답이면 해당 칸 메모 정리

NOTES 테스트 및 배포

브라우저 퍼즐과 서버 판정 검증

Cloudflare Workers에서 퍼즐 생성과 수식 판정을 처리하고, D1에 진행 상태와 완료 기록을 저장합니다. 공개 주소의 진입 페이지와 로컬 테스트를 각각 확인했습니다.

로컬 자동 테스트 24개 통과

스도쿠 유일 해답, 수식 재료, 점수 수정, 게스트 진행과 랭킹, 후보 메모를 검사했습니다.

완료한 퍼즐의 기록

정상 완료한 퍼즐만 랭킹에 남고, 완성된 퍼즐과 칸별 최고 수식을 관전할 수 있습니다.
